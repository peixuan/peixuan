# Corrections

Thank you for taking the time to report or correct an error.

This repository contains a personal blog rather than a collaborative software
project. Corrections to typographical errors, broken links, and factual
mistakes are welcome. New articles, feature requests, and broad rewrites are
outside the scope of this repository.

Please open an issue or submit a focused pull request. When submitting a pull
request:

1. Keep each pull request focused on one change.
2. Preserve the existing front matter and Markdown style when editing posts.
3. Do not commit generated files from `public/` or `resources/_gen/`.
4. Run `hugo` before submitting the change.

Describe the error, the proposed correction, and the reason for it. Include a
reliable source when correcting a factual claim. Do not submit material that
you do not have permission to share.

By submitting original material as part of a correction, you agree that it may
be distributed under the Creative Commons Attribution-NonCommercial-ShareAlike
4.0 International License. See `LICENSE` for the full licensing terms.
